# 系列规划：第一季《梦的解析》

2026-11-12 · 状态：待你确认

## 这是什么

一个每天更新的竖屏短视频系列，发在小红书。第一季的素材全部来自弗洛伊德的《梦的解析》：每集讲一个梦。

**希望观众的感受（你的原话）：** 这个视频非常有趣，说出了自己心里一直想描述但表达不出的感觉，愿意分享给别人。

## 目标与不做的事

**要做到：**

- 每集让人觉得「这说的就是我做过的那个梦」，并且想转给朋友。
- 单看任何一集都完整，连着看能感到一集比一集深。
- 每天一条，中文版和英文版同时出。

**不做：**

- 不做严肃科普，不发论文。不加防御性的学术说明（你的要求）。归属用一句「弗洛伊德在书里写」带过即可。
- 不编造书里没有的话。书里的解释如果偏性、不适合平台，就换一段或不做这集，不把它改写成弗洛伊德没说过的意思。（后半句是我的决定。）
- 不出现 3D 人物（沿用旧规定）。

**算失败的情况：** 观众觉得在上课；或者梦的部分不像自己做过的梦。

## 每集的三步结构

1. **一个现代人常做的梦。** 第一人称 3D 梦境，细节要准到让人笑。
2. **追到书里。** 弗洛伊德记下的同一种梦，或结构相同的案例。
3. **一句让人松口气的解释。** 这是全片的落点。

考试梦这集的样子：

- 毕业多年还梦到坐在考场，卷子一个字不会，醒来愣几秒才想起早就不用考了。
- 弗洛伊德也常做这个梦。他在书里写：人梦到的总是当年考过了的那场。他自己挂过法医学，梦里考的却是植物学、动物学、化学和历史，都是当年提心吊胆、最后还是过了的科目。
- 这种梦出现在第二天有要紧事的前夜。它在说：别怕明天，想想当年考前你有多怕，后来不是没事吗。

我的决定：

- **只讲书里解释的一部分是可以的。** 比如赤身的梦，我们讲「旁人毫不在意、只有你在慌」和童年不知羞的那段，不展开书里更深的那层。讲出来的每句都要在书里找得到。
- **旧规定里的「温和、可以做到的出路」由第三步的落点承担。** 梦这个题材不适合给行动建议，一句让人松口气的话就是出路。

## 画面

你定下的：

- **梦境用第一人称 3D。** 空间里没有人，靠物件说话。
- **讲理论和抽象结构时改用 2D 元素。** 背景仍是虚化、压暗的 3D 场景。两种样式结合着用：
  - **发光线稿：** 细线直接画在画面上，跟着讲述一笔一笔出现，用来讲「谁连到谁」。
  - **书页拼贴：** 旧书页、卷子、印章、小标签，用来讲出处和人物。
- **历史人物用真实照片抠图。** 弗洛伊德、荣格、拉康等，做成拼贴里的贴图。

我的决定：

- 照片只用公有领域或明确可商用的，来源和许可逐张记进 `assets/LICENSES.md`。弗洛伊德的老照片大多可用；拉康去世较晚，照片多数仍有版权，要逐张确认，找不到就不用。
- 2D 元素里的文字也分中英文两套，和字幕放在同一个可切换的图层里。这样 3D 画面仍然只渲染一遍。
- 「不要人物」这条规定针对的是 3D 真人模型，照片抠图不算。
- **旧规定里「写实场景与抽象结构来回切换」保留，两边的内容换了。** 写实的一侧是深夜卧室，另一侧是梦境。原来虚空里的几何体不再是主角，需要时可以留在 2D 讲解的背景里。

## 声音

你定下的：加旁白，科普频道那种男声，中文和英文都试。配音用豆包语音。

我的决定：

- **旁白念的就是字幕，一字不差。** 每屏的字数限制不变（中文每行不超过 13 字，英文约 14 个词）。
- **时间轴改由旁白决定。** 每屏时长取中文和英文两段配音里较长的那个，再留一点气口。这样两个语言版本画面仍然相同。代价是较短的那个语言每屏会多出一点停顿，停顿是否自然只有你听得出来，试点时请你判断。
- **配乐在有人声时自动压低。**
- **我听不到声音。** 所以音色由你选一次、定下来；之后每集我只能检查时长、有没有截断、响度是否达标。读错字、语气怪这类问题需要你抽查。
- **key 由你自己放进本地文件 `studio/.env`**（我会建好模板并让它不进版本管理）。不要贴在对话里。
- 豆包的具体接口、音色名、英文支持情况我没能从文档里查实，等 key 配好后先做一次试听再定。

## 小红书

你定下的：你来登录，我用它看同类爆款、发布视频。

- **看爆款是登录后的第一件事。** 标题写法、封面、单集时长这三项先不定，看完再定。我会放慢速度看，避免账号被风控。
- **发布每次都先给你过目。** 标题、正文、标签、封面我备好，你点头后再发。
- **看爆款其实现在就能做。** 这台电脑上的小红书命令行工具已经连着一个账号，搜索和阅读不需要你再登录。前提是你确认用这个账号。
- **发布视频要走你的 Chrome。** 命令行工具只能发图文；内置浏览器没有上传文件的功能；能上传文件的只有 Chrome 扩展。所以发布用的登录应该在 Chrome 里完成，我还没实际试过。如果不行，我把成片和文字都备好，由你点上传和发布。

### 看爆款的结果（2026-11-12，样本很小：三次搜索、细看两条）

- **最火的是讲「梦在暗示你什么」的大题目。** 一条 8.1 万赞、4.5 万收藏、4604 条评论的视频，一口气讲了好几种梦，时长 5 分 47 秒，AI 画面加旁白，标了「含 AI 生成内容」。
- **只讲考试梦的笔记普遍很冷。** 搜「总是梦到考试」，绝大多数是个位数到几十赞。单讲一个梦，标题就不能只写这个梦。
- **评论区的人都在讲自己的梦。** 这是互动的来源。
- **封面都是两行大字。** 标题多用「你」开头，并许诺这个梦有含义。

据此定下（我的决定，试点后可改）：

- **标题：** 用「你」开头，把这一个梦说成一件人人有份的事，比如「你梦到的那场考试，其实早就考过了」。
- **封面：** 梦境画面加两行大字，第一行是梦，第二行是反转。
- **时长：** 90 秒左右。比爆款短得多，因为我们一集只讲一个梦。
- **正文：** 结尾问一句「你最常做的梦是什么」，把评论区留给观众讲梦。这句只放在笔记正文，不进视频。
- **AI 声明：** 勾选。爆款也标了，没有影响传播。
- **账号：** 用 Chrome 里已登录的「向心棱镜」。
- **上传：** Chrome 扩展一次最多传 10 MB，而之前的成片有 110 MB。试点成片出来后再试压缩或其他办法，不行就由你点上传。

## 推进顺序

1. **你确认用哪个小红书账号**，我看同类爆款，定下标题、封面、时长。
2. **你配好豆包 key**，我出中英文各两三个男声试听，你选定。
3. **做考试梦这集（试点）。** 只做它需要的改动：旁白驱动的时间轴、2D 线稿和拼贴图层、梦境考场。拼贴里的书页文字必须取自真实的原文或扫描件，样稿里那段德文只是示意，没有核对过；考试梦的细节是后来的版本补写的，书页上不标「1900」。记下实际花了多久。
4. **你看试点成片**，提意见，定稿。
5. **攒够 3 集存货再开始日更。** 每天一条能不能撑住，取决于第 3 步量出来的时间。
6. **更新项目说明。** `CLAUDE.md`、`AGENTS.md`、`studio/README.md` 里仍写着「没有旁白」和较严的学术要求，试点定稿后一起改。
