# 试点《考试的梦》制作计划

> **给执行者：** 按任务顺序做，每个任务做完跑它的验证再往下。步骤用 `- [ ]` 勾选。这个目录不是 git 仓库，不需要提交。

**目标：** 做出第一季第 01 集《考试的梦》的中文版和英文版成片，并把生产线升级到支持旁白和 2D 讲解图层。

**做法：** 旁白逐屏合成，量出每屏时长，写成一份 `timeline.json`；画面引擎和配乐都读它。2D 讲解元素放在一个可按语言切换的 DOM 图层里，3D 画面仍只渲染一遍。成片时把旁白和压低后的配乐混在一起。

**技术：** Node 24、Three.js 0.170、puppeteer-core、ffmpeg、Python（numpy）合成配乐、豆包语音合成 2.0（HTTP）。

**规格：** `docs/系列规划-梦的解析.md`（先读它，再读 `CLAUDE.md` 和 `studio/README.md`）。

## 全局约束

- 所有命令在 `studio/` 下运行。
- 画面里不出现 3D 人物。写实场景用空房间加第一人称视角。
- 文案真诚、幽默，不用黑话，不堆比喻，不出现元信息（「本期」「关注我」）。不加防御性的学术说明，归属用一句「弗洛伊德在书里写」带过。
- 不编造书里没有的话。考试梦可用的原文事实只有下面「可用事实」一节列出的那些。
- 旁白念的就是字幕，一字不差。中文每屏最多两行、每行不超过 13 个汉字；英文每屏不超过约 14 个词、最多两行，要自然口语，不逐字直译。
- 全片 90 秒左右（80–100 秒）。
- 豆包 key 只从 `studio/.env` 的 `DOUBAO_API_KEY` 读取。不打印、不写进任何其他文件、不出现在输出里。
- 没有 `timeline.json` 的旧集（`000-demo`）必须照旧能渲染。
- 2D 图层的任何动画都必须是时间 `t` 的纯函数，不能用 CSS transition 或 animation（逐帧截图渲染）。
- 交付前必须看过缩略图（`contact`），中文和英文各看一遍。

## 可用事实（已对照 Brill 英译第三版核对）

- 弗洛伊德把考试梦归在「典型的梦」里，说毕业考试的焦虑梦会顽固地反复出现。
- 一位同行告诉他：这种梦只出现在当年通过了考试的人身上，考砸的人不做。
- 这种梦出现在第二天有一件要负责任的事、可能丢脸的前夜。
- 梦里那句反驳「可我已经是医生了」，其实是梦给的安慰：别怕明天，想想当年考前你有多怕，后来什么事也没有。
- 他自己挂过法医学（博士学位考试的一门），却从没梦到它；梦里常考的是植物学、动物学、化学，这几门他当年提心吊胆，最后过了。中学考试的梦里总在考历史，那门他考得很好。
- 这些细节是后来的版本补写的，画面上不要在它们旁边标「1900」。

## 需要留意的情况

1. **某一屏的合成失败或返回空音频。** `voice` 应报出是哪一屏并以非零状态退出，不写出残缺的 `timeline.json`。
2. **改了一屏文案后重跑 `voice`。** 只重新合成改过的那一屏，其余复用缓存，`timeline.json` 全部重算。
3. **只有中文旁白、没有英文旁白**（或反过来）。时长按现有的那个语言算，成片只出有旁白的语言并打印提示。
4. **英文字幕比中文长很多，换行成三行。** `still --lang en` 检查时要能看出来；文案要改短，不靠缩字号。
5. **2D 元素与底部字幕重叠。** 图层元素一律放在 y < 1300 的区域。

**接口：**
- 产出：`buildTimeline(ep, subs, voice)`，返回 `{ lead, tail, duration, cards: [{ seg, i, start, end }] }`。
  - `voice` 为 `null` 时沿用旧算法：每屏 `sec × (ep.scale ?? 1.08)`。
  - `voice` 为 `{ "S1": [{ zh: 秒, en: 秒 }, …] }` 时：每屏时长 = `max(zh, en) + gap`，`gap = ep.gap ?? 0.45`；缺某个语言就用另一个。
  - `lead = ep.lead ?? 1.4`，`tail = ep.tail ?? 3.2`。
- 产出：`episodes/<id>/timeline.json`，就是上面那个对象的 JSON。引擎和 `synth.py` 发现这个文件就用它的 `start`/`end`，没有就走旧算法。

### 任务 2：2D 讲解图层

**文件：**
- 新建：`studio/engine/overlay.js`
- 修改：`studio/engine/index.html`（加 `<div id="overlay">`，放在 `#scrim` 之后、`#rule` 之前）、`studio/engine/studio.js`（挂到 `S.overlay`，在 `renderAt` 和 `subsAt` 里调用）、`studio/README.md`（补一节 API）

**接口（供 `scene.js` 使用，坐标是 1080×1920 的像素）：**

- `S.overlay.dim(at, out, amount = 0.55)`：这段时间把 3D 画面压暗并虚化（给 `#c` 加 CSS `filter: blur() brightness()`），进出各用 0.6 秒过渡。
- `S.overlay.stroke({ at, out, d, draw = 1.2, color = '#f4ecdc', width = 4, glow = true })`：一条发光线稿。`d` 是 SVG 路径；从 `at` 起用 `draw` 秒画出来（`stroke-dashoffset`），在 `out` 前 0.5 秒淡出。
- `S.overlay.label({ at, out, x, y, zh, en, size = 44, font = 'song', color = '#f4ecdc', anchor = 'middle' })`：一行文字，按当前语言显示 `zh` 或 `en`。`font: 'song'` 用字幕同款衬线体，`'sans'` 用小字同款无衬线体。
- `S.overlay.paper({ at, out, x, y, w, h, rot = 0, src, zh, en })`：一张带纸纹和投影的纸片。给了 `src` 就贴图片（路径相对集目录），否则显示 `zh`/`en` 文字。进场是 0.5 秒的淡入加轻微下落。
- `S.overlay.photo({ at, out, x, y, w, rot = 0, src })`：抠好的透明底照片，进场同 `paper`。
- `S.overlay.update(t, lang)`：引擎每帧调用，把所有元素设到时间 `t` 的状态。

`window.subsAt(t)` 要同时调用 `S.overlay.update`，这样渲染第二种语言时图层文字也会换。

### 任务 3：旁白合成与混音

**文件：**
- 新建：`studio/tools/voice.mjs`、`studio/tools/voice.test.mjs`
- 修改：`studio/tools/render.mjs`（`video` 命令）、`studio/README.md`

**接口：**
- 命令：`node tools/voice.mjs <ep> [--lang zh|en] [--voice <speaker>] [--sample "<文字>" --out <mp3>]`
- 读取 `.env`：`DOUBAO_API_KEY`、`DOUBAO_TTS_RESOURCE_ID`（默认 `seed-tts-2.0`）、`DOUBAO_VOICE_ZH`、`DOUBAO_VOICE_EN`。
- 请求：`POST https://openspeech.bytedance.com/api/v3/tts/unidirectional`，请求头 `X-Api-Key`、`X-Api-Resource-Id`；请求体 `{ user: { uid: 'studio' }, req_params: { text, speaker, audio_params: { format: 'mp3', sample_rate: 24000 } } }`。响应是逐行 JSON，每行的 `data` 是 base64 音频片段，拼起来就是整段；`code` 为 `20000000` 表示结束，其他非零 `code` 是错误。
- 产出：`episodes/<ep>/voice/<lang>/<seg>_<i>.mp3`，`episodes/<ep>/voice/manifest.json`（每屏的文字哈希、音色、时长），`episodes/<ep>/timeline.json`（调用任务 1 的 `buildTimeline`），`episodes/<ep>/out/voice_<lang>.wav`（各屏按 `start + 0.15` 秒摆好的整轨，长度等于全片）。
- 念的文字 = 该屏字幕去掉换行（中文直接拼接，英文用空格拼接）。`small` 小字不念。
- 导出纯函数 `parseTtsStream(text) → Buffer`（解析逐行 JSON、拼音频、遇错误码抛出带 `code` 和 `message` 的异常）和 `speakText(card, lang) → string`，供测试。
- `render.mjs video`：某语言存在 `out/voice_<lang>.wav` 时，用 ffmpeg 把配乐经 `sidechaincompress`（以旁白为侧链）压低后与旁白混合，再做 −16 LUFS 归一；不存在就按原样只用配乐。
